## 最重要：預かり文章の保護
この企画の本文は第三者から預かったメッセージであり、単なるアプリ用データではない。

- 本文をAI判断で要約・言い換え・補完・誤字修正・整文しない。
- 掲載名、絵文字、記号、特殊表記、改行意図を勝手に変えない。
- レイアウトに入らない場合は、文字サイズ・余白・カード枚数・デザイン側を調整する。
- **文章をデザインに合わせない。文章にデザインを合わせる。**
- ユーザーの明示指示または正本側で確認できる変更以外では、既存確定本文を変更しない。

## 更新方法：全置換禁止
最新管理表や新しい一覧を受け取っても、既存アプリデータを丸ごと再生成してはならない。

必ず以下の順で更新する。
1. `main` の正常な最新アプリを取得する。
2. 最新管理表と既存アプリを1人ずつ照合する。
3. 「新規追加」「明示的変更」「削除が明示されたもの」だけを抽出する。
4. 既存確定データは保持する。
5. 差分だけ反映してコミットする。
6. コミット後にファイルを再取得する。
7. 件数・本文・掲載名・絵文字・特殊処理・掲載順を再照合する。
8. 意図しない差分が1件でもあれば完了扱いにしない。

## ミスが起きた場合
1. 追加更新を止める。
2. 直前の正常コミットを特定する。
3. 正常版を土台に戻す。
4. 壊れた版から必要な新規差分だけ抽出する。
5. 1人ずつ再反映する。
6. 再照合してから完了とする。

## 生誕企画の全体構成
- Webメッセージアプリ
- 物理メッセージアルバム
- うみうの手書き手紙
- 9/12 ミブ生誕祭に向けたSNS企画

## 物理アルバム仕様
- アルバム：HAKUBA ポケット式アルバム ビュートクリア KGサイズ80枚 パープル
- ポケット収納寸法：152×102mm
- カード完成サイズ：100×150mm
- A4に3枚面付けして印刷・裁断する方針
- 最初に普通紙で実寸テストし、100%／実際のサイズで印刷してポケット適合確認後に量産

## カードデザイン
- 紫メイン
- 可愛いが甘すぎず、大人っぽさを残す
- 装飾目的のハートは使わない
- 送信者本人の原文に含まれる絵文字・ハート等は原文として保持する
- 通常タイトルは「みんなからのメッセージ」
- 長文・特別カードは個別レイアウト可
- 短文・標準・長文・超長文（2枚）など文章量に応じてレイアウトを変える
- AI画像生成を使う場合は文字なし背景素材まで。最終本文配置・印刷PDFはCanva等で正確に行う

## 掲載順・特殊処理
- 三匹の子豚：`J → むー → ヲワタP` を必ず連続掲載
- 同一人物・重複名の可能性があるものは管理表で確認し、重複掲載しない
- いそやん・ジンベイ・うみう・スタッフ／関係者等の特殊処理を保持する
- 印刷カードに管理番号は出さない

## Webアプリ
基本構成：表紙 → イントロ → 目次 → 通常メッセージ → 特別手紙 → エンディング。
既存の確定済み表示・本文・掲載名・特殊ページを勝手に作り直さない。

## 完了報告の条件
AIが「更新完了」と報告してよいのは、
- GitHub最新正本確認済み
- 必須ルール確認済み
- 差分対象限定済み
- 更新後再取得済み
- 件数・本文・掲載名・特殊処理の再照合済み
- 意図しない変更なし
をすべて満たした場合のみ。
